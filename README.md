# Sistema de gerenciamento de livros (Python)
   Sistema completo para cadastro , consulta e remoção de livros em uma biblioteca virtual desenvolvida em Python.
  

# Funcionalidades
   Menu Principal: Navegação interativa através de loops infinitos controlados.
   Cadastro Automatizado: Gera IDs únicos sequenciais a partir de uma base inicial (RU da faculdade).
   Consulta Tripla: Permite buscar todos os livros, pesquisar por um ID específico ou listar títulos por autor.
   Remoção Segura: Valida o ID digitado e remove a ficha exata da memória, com tratamento para IDs inválidos.

#Tecnologias e Conceitos Aplicados
   Funções e escopo de variáveis locais e globais.
   Estruturas de dados complexas: Listas que armazenam Dicionários.
   Métodos de clonagem de dados (.copy) e inserção em listas (.append).
   Estruturas condicionais avançadas (if / elif / else).
